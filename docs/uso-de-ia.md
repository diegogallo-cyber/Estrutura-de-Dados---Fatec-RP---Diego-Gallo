# Registro de apoio por IA

Conforme a orientação recebida para a atividade, uma ferramenta de IA foi usada como apoio para estruturar e redigir partes do código, do README e do roteiro de testes deste repositório.

O estudante deve revisar os arquivos, executar os testes, validar o comportamento no próprio ambiente, adaptar o relatório às evidências observadas e assegurar que consegue explicar as estruturas, decisões e complexidades em uma demonstração. Este registro não afirma que testes foram executados pelo estudante.
